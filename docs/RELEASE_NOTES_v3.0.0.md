# Persian Palette Studio v3.0.0

Persian-inspired digital palettes with 12 collections, 72 sRGB colors, a TypeScript core and a Persian/English studio.

## Included

- Name/ID lookup with Persian/Arabic normalization and explicit errors for missing or ambiguous input.
- Reference APCA-W3 0.1.9, Material Color Utilities 0.3.0 HCT/CAM16 and digital Oklab interpolation.
- DTCG 2025.10 consumed by Style Dictionary 5; Tailwind exports, generated SwiftUI/Kotlin, Tokens Studio JSON and Figma interchange.
- Standalone HTML with embedded runtime code, styles, icons and fonts. Optional external photos/maps require connectivity.
- Local npm tarball with ESM, CommonJS and TypeScript declarations.

## Evidence and validation

The v3.0.0 suite contains 18 core and 8 integration tests. They cover calculations, formats and static UI connections, not zero browser errors, zero accessibility violations or native-platform compatibility.

All 72 heritage annotations remain unverified. The quality report lists zero measured spectra and 11 coordinate-conflict records. Spectral curves and textures are illustrative. Laboratory authentication and full accessibility certification are not claimed.

## Distribution

Assets include both HTML editions, source ZIP, npm tarball and build manifest. The tarball is distributed through GitHub Releases; public npm registry publication is not implied.
