# مهاجرت از ۲.۱ به ۳.۰

این نسخه به‌دلیل تغییر قرارداد توکن‌ها و بازیابی رنگ، افزایش نسخهٔ اصلی دارد.

| قبلی | نسخهٔ ۳ |
| --- | --- |
| `token.$value` یک HEX بود | برای HEX از `token.hex` استفاده کنید؛ `$value` شیء DTCG است. |
| `document.version` | `document.$extensions['org.persian-palette'].version` |
| نام ناموجود، اولین رنگ را برمی‌گرداند | استثنا؛ خطا را مدیریت کنید یا قبل از انتخاب نام، فهرست پالت را نمایش دهید. |
| ورودی HEX ناقص به مقدار دیگری تبدیل می‌شد | ورودی نامعتبر رد می‌شود. |
| نسبت میکسر خارج از بازه clamp می‌شد | نسبت باید در بازهٔ صفر تا یک باشد؛ در غیر این صورت خطا می‌دهد. |
| `mixHistoricalPigments` | نام پیشنهادی `mixColors`؛ نام قبلی به‌عنوان alias موجود است. |
| DTCG با HEX مستقیم | شیء sRGB با components و alpha و hex. |
| Figma JSON نامشخص | فرمت انتقال مشخص + اسکریپت `figma-import.js`؛ یا خروجی جداگانهٔ Tokens Studio. |
| مقادیر علمی تکراری | از HEX محاسبه می‌شوند؛ یادداشت‌های تاریخی با وضعیت منبع باقی می‌مانند. |

سهم ۰.۴ برای میکسر یعنی ۶۰٪ رنگ اول و ۴۰٪ رنگ دوم. خروجی اصلاح‌شدهٔ مثال لاجورد و زعفران، `#5C6888` است.

فرمول و مختصات اولیه بدون سند جدید قطعی نشده‌اند. اختلاف‌ها را در `evidence.provenance.conflicts` بخوانید. حذف molarMass تأییدنشده از خروجی canonical به معنی حذف دادهٔ اصلی نیست؛ فایل heritage-data.ts نسخهٔ اولیه را حفظ می‌کند.

قالب HTML اکنون در app/template.html و منطق تعامل در app/app.js است. فایل نهایی code_artifact.html را دستی ویرایش نکنید.
