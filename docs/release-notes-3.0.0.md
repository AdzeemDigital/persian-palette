# تغییرات نسخهٔ ۳.۰.۰

- بازیابی فارسی، نویسه‌های عربی معادل، شناسه‌ها و نام‌های مبهم اصلاح شد.
- الگوریتم APCA به کتابخانهٔ مرجع منتقل شد؛ جدول اندازهٔ فونت نیز از همان مرجع خوانده می‌شود.
- HCT/CAM16، طیف تنال و نقش‌های روشن و تاریک Material با کتابخانهٔ مرجع گوگل تولید می‌شوند.
- خروجی DTCG به قرارداد ۲۰۲۵.۱۰ مهاجرت کرد؛ دادهٔ نسخه در extension قرار دارد.
- داده، محاسبات و صادرکننده‌های رابط و پکیج از یک هسته می‌آیند.
- مقادیر مشتق‌شده، از جمله chroma و CIELAB و APCA، خودکار محاسبه می‌شوند.
- تعارض‌های مختصات حفظ و آشکار شده‌اند؛ وضعیت منابع تاریخی و مدل‌های نمایشی قابل مشاهده است.
- ESM و CommonJS با declaration مناسب هر ورودی اضافه شدند.
- خروجی SwiftUI به helper تعریف‌نشده وابسته نیست؛ Kotlin شامل هر دو تم است.
- فونت، استایل، آیکون و کتابخانه‌های اجرایی داخل خروجی HTML قرار دارند.
- مدیریت تمرکز، Escape، گردش Tab، نام کنترل‌ها، کاهش حرکت و صدای خاموش در شروع اضافه شد.
- clipboard منتظر نتیجهٔ واقعی می‌ماند؛ URL دانلود آزاد می‌شود؛ دوربین در خروج/پنهان‌شدن صفحه متوقف می‌شود.
- پکیج نصب محلی، آزمون‌ها و مستندات مهاجرت اضافه شدند.

نسخهٔ قبلی در archive/v2.1.0 نگه‌داری شده است. ثبت عمومی npm، انتشار سایت، بررسی آزمایشگاهی رنگدانه‌ها و ادعای تأیید یونسکو جزو این تحویل نیستند.
